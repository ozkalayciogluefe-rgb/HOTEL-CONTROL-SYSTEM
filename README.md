# 🏨 Hotel Automation System

[🇬🇧 English](#english) 

This project is a hotel automation and management system developed using **Python**, where data is stored and managed in **JSON** format. It allows you to easily manage hotel rooms, customers, reservations, and general hotel operations.

---

## 🚀 Features

- **Customer Management:** Creating new customer records, listing, and updating existing customers.
- **Room Status Tracking:** Viewing available, occupied, or maintenance rooms.
- **Reservation Operations:** Making room reservations, canceling them, and handling check-in / check-out processes.
- **Data Persistence:** Instantly writing and reading all records and changes to `JSON` files.

---

## 🛠️ Technologies Used

- **Language:** Python 3.x
- **Data Storage:** JSON (JavaScript Object Notation)
- **Libraries:** Built-in Python libraries (`json`, `os`, etc.)

# 🏨 Otel Otomasyon Sistemi

[🇹🇷 Türkçe](#turkce)


Bu proje, **Python** kullanılarak geliştirilmiş, verilerin **JSON** formatında saklandığı ve yönetildiği bir otel otomasyon/yönetim sistemidir. Otel odalarının, müşterilerin, rezervasyonların ve genel otel işlemlerinin kolayca yönetilmesini sağlar.

---

## 🚀 Özellikler

- **Müşteri Yönetimi:** Yeni müşteri kaydı oluşturma, mevcut müşterileri listeleme ve güncelleme.
- **Oda Durumu Takibi:** Boş, dolu veya bakımdaki odaları görüntüleme.
- **Rezervasyon İşlemleri:** Oda rezervasyonu yapma, iptal etme ve check-in / check-out işlemleri.
- **Veri Kalıcılığı:** Tüm kayıtların ve değişikliklerin anlık olarak `JSON` dosyalarına yazılması ve okunması.

---

## 🛠️ Kullanılan Teknolojiler

- **Dil:** Python 3.x
- **Veri Saklama:** JSON (JavaScript Object Notation)
- **Kütüphaneler:** Python dahili kütüphaneleri (`json`, `os` vb.)
